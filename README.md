# redactkit

Redact emails, phones, cards, secrets, IPs, and URL tokens before you paste text into an AI tool.

Runs in the browser. Nothing is uploaded.

## Use

Open `index.html` or the live deploy. Paste text. Pick what to find. Hit Redact. Copy the clean output.
